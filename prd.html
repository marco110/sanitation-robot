版本: v1.2
更新日期: 2026-07-09
文档状态: 已更新（新增地图下发车辆选择、矢量地图服务地址配置）

一、项目概述

1.1 项目背景

港口自驾平台是一套面向港口、园区等封闭场景的无人驾驶环卫车辆综合管理平台。系统实现对环卫车辆的接入管理、作业任务规划与调度、实时作业监控、行驶路线配置以及底层地图数据管理等功能，帮助运营人员高效管理和调度环卫作业车辆。

1.2 目标用户

角色 说明
运营管理员 负责车辆管理、作业任务创建与分配、实时监控作业进度、路线配置、停车点管理、地图数据维护

1.3 系统架构

平台基于现有环卫平台进行开发，在现有平台上通过添加菜单进行管理，新菜单命名为"自动驾驶作业管理"，下拉菜单共包含 5 个功能模块：

模块 文件 说明
车辆管理 vehicles.html 基于现有环卫平台车辆进行车辆接入、信息查看、快速新建作业
作业列表 tasks.html 作业任务管理、任务创建与查看
作业监控 monitoring.html 实时车辆位置追踪、车辆控制、视频监控
路线配置 route-config.html 作业路线编辑、停车点管理
地图管理 maps.html 点云/矢量地图上传、下载与版本管理

三、功能模块详细说明

3.1 车辆管理 (vehicles.html)

3.1.1 页面描述

车辆管理模块用于管理当前角色所在组织的接入自动驾驶系统的环卫车辆，支持车辆接入（数据源来自当前环卫平台）、基本信息查看、快速创建作业、车辆删除等操作。

3.1.2 数据模型

车辆字段，数据源自环卫平台：

字段名 类型 说明
车牌号 string 车辆车牌号，如鲁B12345
VIN码 string 车辆识别码（唯一标识）
作业类型 string 车辆作业类型（清扫作业/洒水作业/清运作业）
车辆大类 string 环卫车辆大类（洗扫车/洒水车/压缩车）
车辆小类 string 环卫车辆小类（3吨洗扫车/5方洒水车/7方压缩车）
车辆型号 string 环卫车辆型号（飞碟 WA55/飞碟 D9/飞碟 ZLJ/飞碟 T8）
总质量 string 车辆总质量（kg）
车辆状态 enum 车辆状态：作业中/在线/离线

车辆状态枚举：

状态 颜色标识 说明
作业中 绿色 车辆正在执行作业任务
在线 黄色 车辆已接入但未执行作业
离线 灰色 车辆未连接

3.1.3 功能清单

(1) 状态筛选
  • 提供筛选标签：全部、作业中、在线、离线
  • 每个标签显示对应数量
  • 支持切换筛选条件
(2) 搜索功能
  • 搜索框位于筛选标签右侧
  • 支持按车牌号、VIN码、型号、作业类型、车辆大类、车辆小类进行模糊搜索
(3) 操作按钮
  • 接入车辆（蓝色）：搜索框右侧，点击弹出接入车辆表单
  • 新建作业（绿色）：搜索框右侧，点击弹出新建作业弹窗（不预选车辆）
(4) 车辆列表表格
  • 表头列：车牌号、VIN码、作业类型、车辆大类、车辆小类、车辆型号、总质量(kg)、状态、操作
  • 状态列显示彩色标签
  • 操作列根据车辆状态动态显示：
    • 作业中：查看（跳转作业监控）
    • 在线/离线：新建作业、删除
    • 删除：弹出二次确认对话框
(6) 接入车辆弹窗

表单字段：

字段 类型 是否必填 说明
VIN码 text 是 17位车辆识别码，根据VIN在环卫车辆中进行搜索
  • 提交后将车辆的其他信息列出：车牌号、VIN码、作业类型、车辆大类、车辆小类、车辆型号、总质量(kg)、状态
  • VIN码去重校验
(7) 新建作业弹窗
  • 两步表单向导
  • 第一步 - 基本信息：
    • 作业名称（必填，自动生成默认名称：新作业_YYYYMMDDHHMMSS）
    • 车辆选择（必填，下拉列表，显示所有车辆及其类别和型号，不能选择正在作业的车辆）
    • 已选车辆信息提示（车牌号、作业类型、状态）
    • 路线选择（必填，下拉列表）
    • 已选路线信息提示（里程、预计时长为此路线下完成作业的平均时长，如果此路线下没有完成的作业，则不显示预计时长）
    • 清扫次数（必填，默认值为1，步进器范围1~3次）
  • 第二步 - 作业配置：
    • 工作模式（必填，3选1卡片：洗扫模式/纯洗模式/干扫模式）
    • 子模式选择（必填，前三项为互斥选项即三选一，最后一个选项可以叠加选择）
    • 作业模式（必填，2选1卡片：标准作业/增强作业）
    • 灯光设置（3个开关：工作灯/左转向灯/右转向灯）
  • 创建成功后跳转至作业监控页面（monitoring.html?vehicle=车牌&task=任务名）,创建作业需要下发的任务包括：①车辆上电（未上电需要等ADAS初始化完成再下发剩余任务，时间暂定15S，已上电直接下发剩余任务） ②1.2.2.12清扫任务下发 ③1.2.1.3车辆返回规划路线 ④1.2.2.15上装控制

3.2 作业列表 (tasks.html)

3.2.1 页面描述

作业列表是系统的核心模块，提供作业任务的全面管理，包括任务创建、查看、筛选、搜索，以及路线管理功能。

3.2.2 数据模型

作业列表字段：

字段名 类型 说明
作业状态 string 当前任务的作业状态：作业中/已完成/待开始
作业名称 string 任务设置的作业名称（如：港口A区洗扫作业），下方小字显示子作业模式（如：全洗扫 + 中喷杆）
工作模式 string 洗扫模式/纯洗模式/干扫模式
作业车辆 string 执行作业的车辆车牌号
作业路线 string[] 任务作业路线，因支持任务中进行更改路线，故此字段为数组。
清扫次数 number 执行作业的车辆车牌号
作业模式 enum 标准作业/增强作业
开始时间 string 作业开始时间
结束时间 string 作业结束时间（进行中显示"-"）
耗时 string 当前作业耗时（HH:MM:SS）
进度 number 作业进度百分比（0~100）

工作模式枚举：

模式 颜色 子模式
洗扫模式 #00D4FF 左洗扫、右洗扫、全洗扫（互斥）；中喷杆（可叠加）
纯洗模式 #8B5CF6 左清洗、右清洗、全清洗（互斥）；中喷杆（可叠加）
干扫模式 #F59E0B 左干扫、右干扫、全干扫（互斥）；降尘喷雾（可叠加）

异常数据文件字段：

字段名 类型 说明
id string 文件唯一ID（如：AF001）
desc string 异常描述，如"港口A区3号路口异常碰撞事件"
uploadTime string 文件上传时间（YYYY-MM-DD HH:MM:SS）
occurTime string 异常发生时间（YYYY-MM-DD HH:MM:SS）
duration string 采集时长（HH:MM:SS）
type enum 异常类型：1-碰撞 / 2-紧急制动 / 3-HMI手动触发 / 4-地图采集
size string 文件大小（如：156.3 MB、1.2 GB）

异常类型枚举：

类型编码 类型名称 颜色标识 说明
1 碰撞 红色 #ef4444 车辆发生碰撞时自动触发采集
2 紧急制动 橙色 #f59e0b 车辆触发紧急制动时自动采集
3 HMI手动触发 紫色 #8b5cf6 驾驶员通过HMI手动触发采集
4 地图采集 青色 #00D4FF 用于点云地图数据采集，可关联到地图管理

作业状态枚举：

状态 颜色 说明
标准作业 蓝色 正常标准强度作业
增强作业 紫色 增强强度作业

3.2.3 功能清单

(1) 新建作业弹窗
  • 顶部"新建作业"按钮触发
  • 与车辆管理页面弹窗一致的两步表单
  • 支持从已有作业"再次作业"创建
(3) 作业筛选
  • 筛选标签：全部、待开始、未完成、标准作业、增强作业、已完成
  • 每个标签显示对应数量
(4) 作业搜索
  • 支持多维度搜索：
    • 作业名称
    • 开始/结束日期范围
    • 作业车辆
    • 工作模式
    • 作业路线
  • 支持一键清除所有筛选条件
(5) 作业列表表格
  • 表头列：作业状态、作业名称、工作模式、作业车辆、作业路线、清扫次数、作业模式、开始时间、结束时间、耗时、里程（KM）、进度、操作
  • 状态列显示彩色标签
  • 进度列显示进度条
  • 操作列（固定表格最右侧）：
    • 查看：跳转作业监控页面
    • 再次作业：同新建作业，将当前作业任务的参数（除作业名称外）自动填充
    • 文件（橙色按钮）：打开异常数据文件弹窗，查看该车辆上报的异常数据
    • 删除：二次确认后删除
(6) 异常数据文件弹窗
  • 通过作业列表操作列的"文件"按钮触发
  • 弹窗以表格形式展示该车辆上报的所有异常数据文件
  • 表头列：异常描述、上传时间、异常发生时间、采集时长、类型、文件大小、操作
  • 类型列以彩色标签展示：碰撞（红色）、紧急制动（橙色）、HMI手动触发（紫色）
  • 文件大小按单位区分颜色：GB（橙色）、MB（青色）
  • 操作列包含：
    • 下载按钮：模拟文件下载，点击后显示"下载中..."状态（1.5秒后恢复）

3.3 作业监控 (monitoring.html)

3.3.1 页面描述

作业监控是系统的实时监控核心页面，提供车辆在地图上的实时位置追踪、作业进度查看、远程控制操作以及多路视频监控功能，应用场景为港口调度员在平板上对车辆进行实时监控和远程控制，故需要作平板支持。

创建作业任务后跳转此页面，将会执行以下4个步骤，需要做好信息提示和进度提醒：①车辆上电（未上电需要等ADAS初始化完成再下发剩余任务，时间暂定15S，已上电直接下发剩余任务） ②1.2.2.12清扫任务下发 ③1.2.1.3车辆返回规划路线 ④1.2.2.15上装控制

3.3.2 功能清单

(1) 地图监控（中央主区域）
  • 地图底图：高德卫星图 + 地图管理页面上传的每个地图的最新版本矢量地图url，地图视野需要将规划路线和途经点都显示出俩
  • 规划路径：蓝色虚线显示预设路线
  • 实际轨迹：金色实线显示已行驶路径
  • 途经点：该路线的途经点位置和航向角
  • 车辆标记：绿色三角箭头 + 光晕效果 + 车牌号标签
    • 箭头方向随车辆行驶角度实时旋转
  • 作业进度条：地图顶部浮层，显示当前作业完成百分比
  • 图例：左下角浮层，标注各元素含义
(2) 车辆仪表盘（左侧面板，可折叠）
  • 当前选中车辆的信息卡片
  • 车辆数据仪表：
    • 自驾状态（开启/关闭）
    • 车速（km/h）
    • 电量（%）
    • 档位（P、D、R、N）
    • 钥匙电源（ON/OFF）
    • EPB状态（释放状态-P灯不亮、驻车状态-P灯长亮、释放中-P灯闪烁、驻车中-P灯闪烁）
    • 整车高压（已连接/未连接）
    • 门锁状态（解锁/上锁）
    • 车门开关（开启/关闭）
  • 上装面板：
    • 高压状态（开启/关闭）
    • 油泵状态（开启/关闭）
    • 工作模式（洗扫、纯洗、干扫）
    • 子作业模式（左洗扫+中喷杆）
    • 作业模式（标准/增强）
    • 风机转速（2500 rpm）
    • 水泵转速（2500 rpm）
    • 齿轮泵转速（2500 rpm）
    • 水位低（正常/报警）
    • 污水箱满（正常/报警）
    • 风机电机（正常/报警）
    • 水泵电机（正常/报警）
    • 液压泵电机（正常/报警）
    • 液位传感器（正常/报警）
    • 水路球阀（正常/报警）
  • 故障报警（自动驾驶系统报警信息）
    • 35926：定位丢失报警 15:23:11
(3) 车辆控制面板（地图监控下方和右上方）
  • 底部操作按钮（高频）：
    • 开始（绿色，开始后消失）
    • 暂停/继续（黄色/绿色，根据状态切换，暂停为原地停车）
    • 终止（红色）
  • 右上方操作按钮（低频）：
    • 任务修改：弹窗进行参数更改，可更改清扫次数和作业路线
    • 上装控制：远程控制工作装置
      • 工作模式选择
      • 子模式配置
      • 作业强度切换
      • 灯光控制（工作灯/左转向灯/右转向灯）
    • 暂停至停车点：弹出停车点选择弹窗
  • 断点作业：车辆行驶到断点位置继续作业，按照新建作业处理，名称显示为“原作业任务名称_断点作业1”
  • 调试面板：各种指令单列出来，方便现场调试
(4) 播放控制栏（地图右下角浮层，回放时显示）
  • 播放/暂停按钮
  • 时间轴进度条
  • 当前时间 / 总时长显示
  • 倍速控制：1x / 2x / 4x / 8x
(5) 视频监控
  • 支持2x2网格视图和竖向6路列表视图
  • 摄像头列表：
    • CAM-01 前置摄像头
    • CAM-02 后置摄像头
    • CAM-03 左侧摄像头
    • CAM-04 右侧摄像头
    • CAM-05 作业摄像头
    • CAM-06 鸟瞰摄像头
  • 每路摄像头显示编号、名称、REC状态
  • 支持单路摄像头放大全屏查看（非全屏）

3.4 路线配置 (route-config.html)

路线配置模块用于管理作业路线和停车点，提供可视化路线编辑和停车点地图选点功能。

(1) 路线管理
  • Tab切换：路线管理 / 停车点管理
  • 搜索：按路线名称搜索
  • 新建路线按钮
  • 路线列表：卡片式展示
    • 路线名称、途经点数量

  • 路线编辑弹窗：
    • 路线名称输入

      • "设置航向角"：默认朝上，拖动滑块进行航向角的调整
      • "选择模式"：拖拽调整途经点
      • "清空"：清除所有途经点
    • 途经点列表：
      • 编号标识（途经点1、途经点2、途经点3...）
      • 标签编辑（双击修改名称）

      • 删除单个途经点
  • 路线查看弹窗：只读查看路线详情和途经点
(2) 停车点管理
  • 搜索：按名称或位置搜索
  • 新建停车点按钮
  • 停车点列表：卡片式展示
    • 停车点名称、位置描述、坐标
    • 状态标签：正常/已满/空闲/停用
    • 操作：查看、编辑、删除（二次确认）
  • 停车点编辑弹窗：
    • 停车点名称
    • 位置描述
    • 地图选点：
      • 点击"选择位置"进入选点模式
      • Canvas 地图点击选取坐标
      • 显示经纬度坐标
      • 清空坐标
  • 停车点查看弹窗：
    • 只读展示停车点信息
    • Canvas 地图预览显示停车点位置（P标记）

3.5 地图管理 (maps.html)

3.5.1 页面描述

地图管理模块用于管理系统中的底图数据，包括点云地图和矢量地图的上传、版本管理和预览。支持上传时将点云地图下发到指定车辆，以及为矢量地图配置地图服务地址供作业监控页面加载。

3.5.2 数据模型

地图数据结构：

mapData = {
  '地区名称': {
    lidar: [ 地图版本列表 ],    // 点云地图
    vector: [ 地图版本列表 ],   // 矢量地图
  }
}

地图版本字段：

字段名 类型 说明
id string 唯一ID（LC-点云 / VC-矢量）
regionName string 所属地区名称
version string 版本号（如：1.0.2）
uploadTime string 上传时间
uploader string 上传人
desc string 版本描述
fileSize string 文件大小（MB）
isActive boolean 是否为当前激活版本
type enum 地图类型：lidar / vector
mapServiceUrl string 矢量地图服务地址（仅 vector 类型，非必填），格式如 WFS 服务 URL

五、关键业务流程

5.1 车辆接入流程

  1. 进入车辆管理页面
  2. 点击"接入车辆"按钮
  3. 填写车辆信息（VIN、车牌号、作业类型、车辆信息等）
  4. 提交，车辆自动设为"在线"状态

5.2 作业创建与下发流程

  1. 在车辆管理或作业列表页面，点击"新建作业"
  2. 第一步：填写基本信息（名称、车辆选择、路线选择、清扫次数）
  3. 第二步：配置作业参数（工作模式、子模式、作业状态、灯光设置）
  4. 确认创建，跳转至作业监控页面

5.3 作业监控与控制流程

  1. 作业监控页面实时展示车辆位置和作业进度
  2. 可通过底部按钮控制作业状态（开始/暂停/继续/终止）
  3. 可通过参数下发修改当前作业配置
  4. 可通过上装控制远程控制车辆工作装置
  5. 可查看多路视频监控画面
  6. 可查看故障报警信息

5.4 异常数据上报显示

  1. 在作业列表页面，点击操作列的"文件"按钮
  2. 弹窗展示该车辆上传的作业异常数据文件（碰撞、紧急制动、HMI手动触发），此页面不包含“地图采集”类型
  3. 对于需要存档的异常文件，点击"下载"按钮进行下载

六、非功能需求

6.1 浏览器兼容性

  • 推荐 Chrome 90+ / Edge 90+
  • 支持 Safari
  • 支持 平板端查看

6.2 性能要求

  • 地图加载时间 < 3s
  • 页面切换无明显卡顿
  • 实时位置更新延迟 < 1s
